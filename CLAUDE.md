# CLAUDE.md — butter_blob

DevButter's company-wide blob store: one FastAPI service that stores and serves the
files (blobs) created or uploaded by any DevButter app or API, backed by S3 (MinIO
locally). Every blob is bound to the API that created it (its `namespace`); a
DevButter admin sets per-namespace limits (storage quota, max file size, allowed
formats, image compression). Files can be permanent or temporary (auto-expiring).

## Prompt-driven workflow

This repo is built in numbered slices under [`docs/prompts/`](docs/prompts/).

- **[`docs/spec.md`](docs/spec.md) is authoritative.** If code and spec disagree, the
  spec wins unless you're deliberately changing it (update it in the same slice).
- **Implement one `docs/prompts/NN-*.md` at a time.** Each prompt lists
  *Goal / Depends on / Reference / Files / Steps / Acceptance / Notes*. Don't start
  a prompt whose "Depends on" isn't merged.
- **Tick [`docs/TODO.md`](docs/TODO.md)** as you finish each prompt's deliverables and
  its acceptance check.
- Prompts **00–03 are done** (scaffold, settings/core, db/alembic, storage).
  **04–11** finish the service. **12–16** are phase-2 / previously "out of scope"
  and are written to be run by **Codex** (`codex` CLI / `codex:rescue`).

## Architecture

Standard DevButter microservice shape, cloned from `../butter_relay`:

```
app/
├── main.py           # FastAPI(): setup_logging → configure_metrics → register_middleware
│                     #   → register_exception_handlers → include_router(...) ; /health ; /health/ready ; /
├── settings/
│   ├── config.py     # pydantic-settings Settings, module-level `settings`
│   ├── logging_config.py
│   └── middleware.py # RequestContextMiddleware (request id, timing, request-level EMF)
├── core/
│   ├── decorators.py    # log_call / log_errors
│   ├── exceptions.py    # DomainError subclasses + self-registering handlers (registry pattern)
│   ├── metrics.py       # CloudWatch EMF: configure_metrics(), emit_metrics(metrics, dimensions=None)
│   ├── observability.py # emit_blob_metric(name, value, unit, *, namespace, **dims)
│   ├── storage.py       # BlobStorage — boto3 S3 wrapper; every call via asyncio.to_thread;
│   │                    #   botocore errors → StorageError / NotFoundError
│   └── dependencies.py  # DbSession, RequireServiceApiKey, RequireAdminApiKey, CallerNamespace
├── db/
│   ├── base.py          # Base(DeclarativeBase)
│   ├── session.py       # async engine + get_db_session
│   └── all_models.py    # import list for Alembic autogenerate / test create_all — ADD EACH DOMAIN HERE
├── <domain>/            # one package per resource, the fastapi-builder 5/6-file shape:
│                        #   router.py schemas.py models.py service.py repository.py [dependencies.py]
alembic/                 # async env.py, timestamp file_template
tests/                   # pytest + httpx ASGITransport; sqlite in-memory; storage faked (tests/fakes.py)
```

Follow `anthropic-skills:fastapi-builder` for anything not covered here (thin routers,
`@log_errors` on services, domain exceptions only above the repository, `IntegrityError`
→ `ConflictError` in the repository via a `_commit_or_raise_conflict` helper).

## Auth — three header trees

| Tree | Header(s) | Missing/invalid | Who |
|---|---|---|---|
| `/v1/public/*` | none | — | anyone (serves `public` blobs only) |
| `/internal/v1/*` | `X-Service-Api-Key` + `X-Blob-Namespace` | 404 (key) / 422 (namespace) | DevButter apps & APIs |
| `/admin/v1/*` | `X-Admin-Api-Key` | 404 | DevButter admin (sets limits) |

`X-Blob-Namespace` identifies the calling API and owns every blob it creates.
Cross-namespace access on `/internal/v1/*` returns **404**.

## Run

```bash
poetry install
poetry run pytest
poetry run ruff check .
poetry run mypy .

# migrations (needs a DB; DATABASE_URL from .env)
poetry run alembic revision --autogenerate -m "add blobs"

# full stack (needs infra/: devbutter_shared network + shared-postgres + minio)
cp .env.example .env
docker compose up --build          # entrypoint runs `alembic upgrade head`, serves on :8003
```

## Conventions

- **Python 3.12.** Poetry only — never a `requirements.txt`.
- Async SQLAlchemy 2.0 (`Mapped[...]` / `mapped_column`), one `AsyncSession` per request.
- Enums: `str, enum.Enum` stored in `String(...)` columns (no native PG enum).
- UUID primary keys (`default=uuid.uuid4`); `DateTime(timezone=True)`, `server_default=func.now()`.
- Migrations autogenerated **and reviewed** before commit; add every new domain's
  `models` module to `app/db/all_models.py`.
- Metrics: file-level metrics go through `app.core.observability.emit_blob_metric`
  from the **service layer**, never the router. Every file metric carries a
  `Namespace` dimension.
- Never let a botocore or SQLAlchemy exception escape `core/storage.py` /
  `<domain>/repository.py` — translate to an `app.core.exceptions` type.
- `mypy` runs `strict = true` on `app/`; `tests.*` relaxes the untyped-def rules.
- **CHANGELOG.md / RELEASE_NOTES.md are written in pt-BR** (matches the sibling
  services); code, comments, `docs/` and this file are in English.
- Default branch: **`master`**.
